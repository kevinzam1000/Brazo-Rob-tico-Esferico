Brazo Robótico Esférico

Proyecto Integrador de Mecatrónica

Descripción del Proyecto

Este proyecto consiste en el diseño, análisis cinemático y construcción de un brazo robótico esférico de bucle cerrado controlado mediante microcontrolador.

El sistema permite calcular y ejecutar trayectorias exactas combinando motores paso a paso, redes de transmisión cinemática y encoders magnéticos para retroalimentación en tiempo real.

Especificaciones Técnicas

Configuración

Robótica Esférica (R-R-P)

Controlador

Arduino Mega 2560

Actuadores Principal

NEMA 17 + Driver TB6600

Sensórica

Encoder Magnético AS5600

Componentes Principales

Arduino Mega

Tarjeta de procesamiento central encarga del cálculo de trayectorias y generación de pulsos de paso.

Motores NEMA 17 & Drivers TB6600

Proporcionan el par de torsión necesario para el posicionamiento articular con alta resolución.

Sensor Magnético AS5600

Encoder absoluto I2C de 12 bits para medir la posición angular del eje articular en bucle cerrado.

Motor 28BYJ-48

Actuador auxiliar para mecanismos de sujeción o grados de libertad secundarios.

Funcionamiento

El usuario introduce las coordenadas cartesianas o angulares deseadas. El controlador ejecuta el modelo cinemático para traducir la posición en cantidad de pasos del motor.

Mediante la lectura constante del encoder AS5600, el sistema verifica que no existan pérdidas de pasos y corrige desviaciones en tiempo real.
