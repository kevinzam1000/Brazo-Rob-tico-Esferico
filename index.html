Brazo Robótico Esférico

Proyecto Integrador de Mecatrónica

Descripción del Proyecto

Este proyecto consiste en el diseño, análisis cinemático y construcción de un brazo robótico de configuración esférica controlado mediante un microcontrolador Arduino.

El sistema permite calcular y ejecutar trayectorias exactas para posicionar el brazo en coordenadas específicas, utilizando motores paso a paso, sistemas de transmisión por correa y retroalimentación de posición mediante un encoder magnético absoluto.

Componentes Principales

Arduino Mega

Microcontrolador encargado del procesamiento numérico de coordenadas y generación de pulsos para los drivers.

Motores NEMA 17 & Driver TB6600

Proporcionan el torque adecuado para el movimiento articular y el control de fuerza en los ejes.

Sensor Magnético AS5600

Encoder absoluto I2C de 12 bits para lectura angular precisa y verificación de posición del eje.

Motor 28BYJ-48

Actuador auxiliar compacto utilizado para mecanismos secundarios o efector final.

Funcionamiento

El usuario introduce las coordenadas deseadas a través de la interfaz o puerto serie, y el sistema calcula cinemáticamente el número de pasos requerido para cada motor.

Durante la ejecución, la señal de pulsos activa los drivers y el encoder AS5600 permite retroalimentar la posición real para evitar desviaciones o pérdida de pasos.

Programación y Control

El firmware está desarrollado en C++ para la plataforma Arduino. Recibe los parámetros de entrada y los traduce en señales de paso y dirección (`STEP` / `DIR`). 

// Estructura base de control para drivers paso a paso

const int stepPin = 3;
const int dirPin = 4;
const int enablePin = 5;

void setup() {
  pinMode(stepPin, OUTPUT);
  pinMode(dirPin, OUTPUT);
  pinMode(enablePin, OUTPUT);
  digitalWrite(enablePin, LOW); // Habilita driver TB6600
}
