Proyecto: Brazo Robótico

Descripción

Brazo robótico desarrollado como proyecto de mecatrónica. El sistema permite controlar la posición del brazo mediante coordenadas y motores paso a paso.

Demostración

En el siguiente video se muestra el funcionamiento del robot.

Componentes

  • Arduino Mega
  • Motores NEMA 17
  • Motor 28BYJ-48
  • Drivers para motores
  • Sensor AS5600
